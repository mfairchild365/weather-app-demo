# weather-demo

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) for every commit in this repo:

```
<type>[optional scope]: <description>

[optional body]
```

Common types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`, `build`, `perf`, `style`.
Keep the description short, imperative, lowercase (e.g. `feat: add disclosure widget skill`).
Use `!` after the type/scope (e.g. `feat!:`) or a `BREAKING CHANGE:` footer for breaking changes.

## Accessibility

All UI work follows `.github/skills/building-accessible-ui/SKILL.md` (WCAG 2.2 AA). Specs and plans
for user-facing features must include the accessibility contract before implementation starts —
see that skill's `references/spec-driven-development.md`.
